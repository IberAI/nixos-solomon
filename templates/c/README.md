# Project

General C development flake for Nix 26.05.

## Start

```sh
nix develop
```

Optional direnv setup:

```sh
cp .envrc.example .envrc
direnv allow
```

## Shells

- `nix develop`: C stuff c++ c

## Edit First

Open `flake.nix` and edit the package categories near the top. Delete anything
you do not need.
